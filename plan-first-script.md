## Notes for the take

- **Let the animation finish.** Wait for each step's animation before the next click; steps 1, 3, 5 and 6 animate the longest. If a line runs long, hold the click rather than speeding up.
- **Step 7 is the aha.** Pause about half a second after "Both pull requests passed review." before "Living Map's check blocks the merge."
- **Codex is labelled "preview"** because the Codex plugin isn't shipped yet. If Codex really reads the decision from Living Map in the recording, say so in the interview. If that screen is staged, keep the label and don't claim it's live.
- **No outro.** The last line plays over the final map: the system in grey, with the agreed decision still lit.
